# 🚀 Демонстрация Facial Emotion Recognition

## Быстрый старт для демонстрации

### Вариант 1: WebRTC версия (рекомендуется) 🌟
```bash
# Установите зависимости
pip install streamlit-webrtc av

# Запустите WebRTC версию
python -m streamlit run web_app/app_webrtc.py --server.port 8501
```
Откройте: http://localhost:8501

**Преимущества WebRTC:**
- ✅ Работает в браузере (не нужен доступ к системной камере)
- ✅ Реальное время с низкой задержкой
- ✅ Стабильная работа без ошибок рекурсии
- ✅ Современная технология

### Вариант 2: Минимальная версия (только изображения)
```bash
# Запустите минимальную версию
python -m streamlit run web_app/app_minimal.py --server.port 8501
```
Откройте: http://localhost:8501

### Вариант 2: Демонстрация для внешних пользователей

#### Шаг 1: Запустите сервер
```bash
# Для доступа из сети
python -m streamlit run web_app/app_minimal.py --server.address 0.0.0.0 --server.port 8501
```

#### Шаг 2: Найдите ваш IP-адрес
```bash
# Windows
ipconfig

# Или используйте скрипт
python run_demo_server.py
```

#### Шаг 3: Поделитесь ссылкой
Дайте пользователям ссылку: `http://YOUR_IP:8501`

### Вариант 3: Использование ngrok (рекомендуется)

1. **Скачайте ngrok**: https://ngrok.com/download
2. **Запустите приложение**:
   ```bash
   python -m streamlit run web_app/app_minimal.py --server.port 8501
   ```
3. **В другом терминале**:
   ```bash
   ngrok http 8501
   ```
4. **Поделитесь ссылкой** из ngrok (например: https://abc123.ngrok.io)

## Устранение проблем

### Если приложение не запускается:
1. Проверьте, что виртуальное окружение активировано
2. Убедитесь, что все зависимости установлены
3. Проверьте, что модель загружена

### Если модель не найдена:
1. Убедитесь, что файл `converted_best_hpo_optimized.keras` существует
2. Или загрузите модель из Dropbox (автоматически)

### Если порт занят:
```bash
# Используйте другой порт
python -m streamlit run web_app/app_minimal.py --server.port 8502
```
