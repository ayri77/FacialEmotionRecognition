# Руководство по публикации веб-приложения

## Варианты деплоя для общего доступа

### 1. 🚀 Heroku (Бесплатно)
```bash
# Установка Heroku CLI
# Скачайте с https://devcenter.heroku.com/articles/heroku-cli

# Логин
heroku login

# Создание приложения
heroku create facial-emotion-recognition

# Деплой
git push heroku main
```

### 2. 🌊 Railway (Бесплатно)
- Подключите GitHub репозиторий
- Автоматический деплой из Docker
- Получите публичный URL

### 3. ☁️ Render (Бесплатно)
- Подключите GitHub
- Выберите Docker контейнер
- Автоматический деплой

### 4. 🐳 Docker Hub + VPS
```bash
# Сборка и публикация образа
docker build -t your-username/facial-emotion-web .
docker push your-username/facial-emotion-web

# Запуск на VPS
docker run -p 80:5000 your-username/facial-emotion-web
```

## Быстрый старт с Ngrok (Рекомендуется)

### Шаг 1: Установка
```bash
# Windows
winget install ngrok.ngrok

# Или скачайте с https://ngrok.com/download
```

### Шаг 2: Запуск туннеля
```bash
# После запуска Flask приложения
ngrok http 5000
```

### Шаг 3: Поделиться ссылкой
Ngrok покажет публичную ссылку типа:
`https://abc123-def456.ngrok.io`

**Отправьте эту ссылку друзьям - они смогут использовать ваше приложение!**

## Особенности публикации

### ✅ Что работает:
- Веб-интерфейс
- Камера (в браузере пользователя)
- Симуляция эмоций
- Все визуальные эффекты

### ⚠️ Ограничения:
- Камера работает только на HTTPS (безопасные соединения)
- Некоторые браузеры требуют разрешения на камеру
- Производительность зависит от интернет-соединения

### 🎯 Для презентации:
Ngrok - идеальный вариант:
- Быстрая настройка (2 минуты)
- Публичная ссылка
- Работает с камерой
- Безопасное HTTPS соединение
