# Анализ проекта распознавания эмоций по лицу - Итоговый отчет

**Дата анализа:** 13 октября 2025
**Проект:** Facial Emotion Recognition
**Автор:** Павло Борисов

---

## 🎯 Обзор проекта

Проект представляет собой комплексное исследование различных подходов к распознаванию эмоций по лицу с использованием глубокого обучения. Было проведено множество экспериментов с различными архитектурами, от простых CNN до современных методов Transfer Learning и оптимизации гиперпараметров.

### Цель проекта
- Сравнить различные архитектуры нейронных сетей для распознавания эмоций
- Найти оптимальную модель для классификации 4 классов эмоций: happy, neutral, sad, surprise
- Исследовать влияние различных техник регуляризации и аугментации данных
- Провести оптимизацию гиперпараметров для достижения наилучших результатов

## 📊 Анализ данных

### Структура датасета
- **Общий размер:** ~20,000 изображений
- **Разделение:** Train (15,109) / Validation (4,977) / Test (128)
- **Размер изображений:** 48×48 пикселей
- **Формат:** Grayscale и RGB
- **Классы:** 4 эмоции с незначительным дисбалансом

### Классовые веса
Для решения проблемы дисбаланса классов были вычислены веса:
```python
CLASS_WEIGHTS = {
    0: 0.950,  # happy
    1: 0.950,  # neutral
    2: 0.949,  # sad
    3: 1.190   # surprise (меньше всего примеров)
}
```

## 🏗️ Архитектуры моделей

### 1. Базовые CNN модели

#### CNN-1 (Baseline)
- **Архитектура:** 3 блока × 2 сверточных слоя
- **Параметры:** 288,740
- **Результат:** 65.6% test accuracy
- **Назначение:** Базовый уровень для сравнения

#### CNN-2 (Deep Regularized)
- **Архитектура:** 4 блока × 3 сверточных слоя
- **Параметры:** 1,962,308
- **Регуляризация:** L2(0.001), Dropout(0.4)
- **Результат:** 74.2% test accuracy ⭐
- **Вывод:** Хороший баланс сложности и производительности

### 2. Сложные CNN архитектуры

#### Complex CNN (5 Blocks)
- **Архитектура:** 5 блоков × 2 сверточных слоя
- **Параметры:** ~8.7M
- **Каналы:** (64, 128, 512, 512, 128)
- **Результаты:**
  - Grayscale: 73.4% - 77.3% test accuracy
  - RGB: 76.6% - 79.8% test accuracy ⭐

#### Complex CNN с различными конфигурациями
- **GS192 (сильная регуляризация):** 77.3% test accuracy
- **RGB с регуляризацией:** 76.6% test accuracy
- **RGB без регуляризации:** 79.8% test accuracy (лучший результат)

### 3. Transfer Learning модели

#### VGG16
- **Параметры:** 14.8M
- **Pre-trained:** ImageNet weights
- **Результат:** 71.1% test accuracy
- **Вывод:** Уступает кастомным CNN для grayscale эмоций

#### ResNet50V2
- **Параметры:** 24.1M
- **Pre-trained:** ImageNet weights
- **Результат:** 70.3% test accuracy
- **Стратегия:** Frozen base + unfreeze last blocks

#### DenseNet121
- **Параметры:** 7.3M
- **Результат:** 57.2% test accuracy
- **Проблема:** Недостаточная настройка для задачи

#### EfficientNetV2B2
- **Параметры:** 9.2M
- **Результат:** 36.7% test accuracy
- **Проблема:** Нестабильная сходимость

## 🔬 Эксперименты и исследования

### 1. Сравнение Grayscale vs RGB

**Эксперимент:** Тестирование одних и тех же архитектур на grayscale и RGB данных

**Результаты:**
- RGB показал лучшие результаты в большинстве случаев
- Grayscale: 73.4% - 77.3% test accuracy
- RGB: 76.6% - 79.8% test accuracy
- **Вывод:** Цветная информация помогает в распознавании эмоций

### 2. Исследование архитектурных параметров

#### Влияние размера каналов
- **Базовые каналы:** (64, 128, 512, 512, 128)
- **Увеличенные каналы:** (96, 192, 512, 512, 192)
- **Результат:** Незначительное улучшение при увеличении сложности

#### Влияние регуляризации
- **L2 regularization:** 0.0001 - 0.01
- **Dropout:** 0.3 - 0.6
- **Вывод:** Сильная регуляризация важна для предотвращения переобучения

### 3. Аугментация данных

**Тестированные стратегии:**
- **Light:** Только horizontal flip + brightness
- **Medium:** Flip + brightness + contrast
- **Strong:** Flip + brightness + contrast + rotation

**Результат:** Medium аугментация показала лучший баланс

### 4. Оптимизация гиперпараметров (HPO)

#### Optuna оптимизация
- **Триалы:** 40 экспериментов
- **Цель:** Улучшение базового результата 80.0%
- **Лучший результат HPO:** 76.8% validation accuracy

**Оптимальные параметры:**
```python
{
    "architecture": "complex",
    "channels_multiplier": 1.2,
    "dropout": 0.427,
    "l2_reg": 0.001318,
    "learning_rate": 0.000100,
    "batch_size": 64,
    "augmentation": "medium"
}
```

#### Финальная модель с HPO
- **Test accuracy:** 82.9% ⭐
- **Улучшение:** +2.9% относительно базового уровня 80.0%

## 🔍 Анализ ошибок и вызовов

### 1. Основные проблемы
- **Переобучение:** Особенно в сложных моделях
- **Нестабильность:** EfficientNet и некоторые DenseNet эксперименты
- **Дисбаланс классов:** Класс "surprise" представлен меньше всего

### 2. Успешные решения
- **Классовые веса:** Эффективное решение дисбаланса
- **Сильная регуляризация:** L2 + Dropout для предотвращения переобучения
- **RGB vs Grayscale:** Цветная информация улучшает результаты
- **HPO:** Оптимизация гиперпараметров дала значительное улучшение

### 3. Неудачные эксперименты
- **Focal Loss:** Результат 10% - модель не обучилась
- **EfficientNet:** 36.7% - проблемы со сходимостью
- **DenseNet:** 57.2% - недостаточная настройка
